# Парсер
Scrapy-парсер для сбора информации о товарах интернет-магазина alkoteka.com по заданным категориям. Данные собираются в формате JSON с учётом выбранного региона — Краснодар.

# Описание
Парсер принимает список ссылок на категории и собирает подробную информацию о каждом товаре, включая: название, бренд, разделы, цену, наличие, изображения, видео, маркетинговые тэги и характеристики. Результат сохраняется в структурированном JSON, готовом для анализа.  

# Запуск
cd alkoteka
scrapy crawl spider_name -O result.json
